# Talleres

Proyecto de validación de datos personales para la capacitación.

## Archivos

- `validacion.py`: funciones para validar una cédula de 10 dígitos y nombres/apellidos.

## Uso

Ejecuta el módulo directamente con Python:

```powershell
python validacion.py
```

Luego ingresa cédula, nombre y apellido cuando se solicite.

## Funciones principales

- `validar_cedula(cedula: str) -> bool`
- `validar_nombre(nombre: str) -> bool`

Estas funciones devuelven `True` si el dato cumple el formato esperado.
